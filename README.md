# Simulink_dirtion 

**用法：选择目标函数后运行本代码；**

dirtion.m 为函数文件，ditton.mlapp为app  ，此两者作用相同。
此脚本汇集一些 建模\仿真时常用函数,做成app方便使用
1. 对端口序号重新命名。使用方法：逐次点击输入输出端口再运行程序 或点击app上对应按钮.要求：若重新命名需重新打开app或清除workspace上的信息。 
2. 设置模块与模块之间的连线。使用方法：选择输出方及接收方对应端口号,点击脚本进行连接。
3. 复制模块的Mask标定量信息。 使用方法:选择复制方模块和目标模块,点击脚本进行复制。
4. 修改模块大小。使用方法:点击目标模块,运行脚本.默认模块长随 最大输入输出数量变化,宽度为长度0.6倍.
5. 对Mask的格式进行修改 将格式改为'edit'.可自定义修改类型
6. 根据输出、输入模块制作fromworks模块,用于模型仿真.  1 输入 2输出 3输入输出
7. 整理模块布局
8. 根据workspace上的信号信息制作fromworks模块,用于模型仿真
